Methodology

Reproducible field procedure used on 2026-08-05. Session: Authenticated Safari.

Default clean state

Every trial started from a known home surface.

    Procedure

    One parameter. One observation window. Then reset.

    What we measured each trial

    URL

    Final href, path, search, hash after settle (and after auto-navigation to /c/…).

    Composer

    Pre-fill vs empty vs auto-submit; multiline preservation; long-prompt survival.

    Mode

    Model select label + localStorage modes-selected-id.

    Privacy / History

    Private toggle aria, disclaimer text, whether a History row appeared.

    Discovery notes (candidates only)

    Bundle strings suggested names to try. Effects were never claimed from source alone.

      Honesty rules

      • Report only what appeared in the browser.
      • Say “no visible effect” instead of guessing.
      • Mark upgrade-gated and unresolved cases explicitly.
      • Prefer exact URLs tested over paraphrased patterns.

      Re-run checklist

      1. Authenticated desktop browser on grok.com.
      2. Reset mode to a known id (?mode=fast).
      3. Leave private mode (Switch to Default Chat).
      4. Walk the parameter list; tee notes into data/findings.json.
