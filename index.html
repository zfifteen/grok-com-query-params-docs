Golden path

  1. Encode the prompt with encodeURIComponent.
  2. Use ?q= to auto-submit.
  3. Add &mode=expert (or fast / auto) when needed.
  4. Append #private last for private runs.

Hard rules from the run

  • prompt= and model= did nothing.
  • Privacy is a hash (#private), not ?private=.
  • Non-empty q auto-sends — it does not merely pre-fill.
  • mode=heavy stayed put without SuperGrok Heavy.
